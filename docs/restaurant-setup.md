# تجهيز جهاز المطعم — بروست Cloud 2.1

المثبّت: `BroostPOS_Cloud_2.1_Advanced.exe`.

## قبل التثبيت

- Windows 10 إصدار 22H2 أو Windows 11 بنظام 64 بت، واتصال إنترنت يعمل.
- جهّز رمز دخول الكاشير الحالي. ربط Railway مضمّن في النسخة الخاصة بالمطعم.
- وصل طابعة الفواتير الحرارية المتوافقة مع ESC/POS وثبّت تعريفها في Windows.
- أغلق الكاشير بعد حفظ الفاتورة الحالية. المثبّت يتحقق من التطبيقات المفتوحة قبل التحديث.
- استخدم نفس حساب Windows الذي سيعمل عليه الكاشير؛ التثبيت وإعدادات الجهاز تخص هذا الحساب.

## خطوات التجهيز

1. افتح المثبّت واتبع الخطوات بالعربي؛ اختصار سطح المكتب محدد افتراضيًا.
2. افتح البرنامج. يظهر معالج تجهيز الجهاز في أول تشغيل للنسخة 2.1.
3. أعد فحص الجهاز إذا ظهر خطأ في التوافق أو الصلاحيات أو المساحة.
4. أدخل رمز الكاشير واضغط اختبار الاتصال والدخول. الاختبار يقرأ حالة السيرفر والمنيو فقط؛ لا ينشئ طلبًا أو وردية ولا يستهلك رقم فاتورة.
5. اختر الطابعة الفعلية ومقاس الورق 58 أو 80 مم وحجم الكتابة، ثم اطبع ورقة الاختبار.
6. تأكد بنفسك من خروج الورقة ووضوح العربية والأرقام والـ QR وعدم قص أطرافها، ثم علّم التأكيد. إرسال الورقة إلى Windows وحده لا يكفي.
7. اختر اسم الجهاز، والتشغيل مع Windows وملء الشاشة إذا رغبت. F11 يبدّل وضع ملء الشاشة.
8. احفظ الإعدادات ثم سجّل دخول الكاشير وافتح الوردية عند بداية العمل.

لا يلزم إعادة التجهيز في كل تشغيل. تغيير ربط السيرفر أو المفتاح يستلزم إعادة فحصه.

## عند حدوث مشكلة

- من شريط البرنامج افتح «تجهيز الجهاز / فحص وإصلاح» لإعادة الفحوص أو تعديل الطابعة. فتح المعالج لا يعيد تحميل صفحة الكاشير ولا يمسح السلة الحالية.
- فشل الاتصال: اتبع الرسالة؛ قد يكون السبب الإنترنت، ضبط الوقت، رمز الدخول، صلاحية الجهاز أو إصدار السيرفر. بعد محاولات دخول كثيرة انتظر خمس دقائق.
- الطابعة لا تظهر: راجع التوصيل والتعريف ثم حدّث القائمة. طابعات PDF وXPS لا تظهر كطابعات فواتير.
- إذا اختفت الطابعة المحددة، لا يحوّل البرنامج الفاتورة تلقائيًا إلى طابعة مختلفة.
- يمكن حفظ تقرير الفحص من أي صفحة وإرساله للدعم. التقرير لا يتضمن رمز الكاشير أو مفتاح الربط أو تفاصيل الطلبات.
- اختيار «إعادة الاتصال» يعيد تحميل صفحة الكاشير؛ يظهر تأكيد قبل فقد السلة غير المحفوظة.

التثبيت وإعادة التثبيت يحتفظان بإعدادات الجهاز ولا يستوردان قواعد بيانات قديمة ولا يصفران بيانات المطعم السحابية. اختبارات النسخة الآلية تستخدم بيئة معزولة؛ اختبار الطابعة الفعلية وأول طلب حقيقي في لوحة الإدارة يتمان على جهاز المطعم أثناء التسليم.
