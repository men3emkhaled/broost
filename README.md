# BROOST POS — نسخة أوفلاين

تطبيق الكاشير يعمل محليًا على Windows بقاعدة SQLite. لا يبدأ سيرفر، ولا يرسل
الفواتير أو المنيو إلى موقع، ولا يحتاج اتصال إنترنت أثناء التشغيل.

## التشغيل

على هذا الجهاز شغّل `start_offline.bat`. عند النقل إلى جهاز Windows آخر ثبّت
Python 3.12 أولًا، ثم نفّذ مرة واحدة:

```bat
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

بعدها يمكن تشغيل `start_offline.bat` بدون إنترنت. أول تشغيل ينشئ
`broost_pos.db` محليًا بالمنيو الأساسي (42 صنفًا في 8 تصنيفات)، بدون فواتير
أو عملاء قدامى. النسخ الاحتياطية تحفظ داخل `backups`.
رقم دخول الوردية الافتراضي `1111`، ويمكن تغييره من إعدادات النظام.

## الواجهة

شاشة الكاشير مقسمة إلى التصنيفات، الأصناف، السلة، والطلبات الجارية. إعداد
الشاشة المدمج يستهدف 1366×768 أو أكبر، ويضغط البطاقات والأزرار عند تصغير
المساحة أو تكبير عرض Windows إلى 125%. أدوات الإدارة الإضافية موجودة في
قائمة الإعدادات على الشاشات الصغيرة. صفحة الكاشير نفسها بلا تمرير؛ قوائم
الطلبات أو السلة الطويلة يمكن تمريرها داخل منطقتها عند الحاجة.

## الفحص

```bat
set QT_QPA_PLATFORM=offscreen
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

الفحص يستخدم قاعدة مؤقتة ويمنع الاتصال الشبكي والطباعة الفعلية. يمكن فحص
الطابعة من إعداداتها داخل التطبيق. بناء ملف تثبيت جديد يتم على جهاز Windows
نظيف ومفحوص باستخدام `build_windows.bat` بعد تثبيت
`requirements-build.txt` وInno Setup، ولا تُستخدم ملفات EXE القديمة.
